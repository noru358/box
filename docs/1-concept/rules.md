# 지금 확정된 규칙 (v12, 덜어낸 판)

← [문서 지도](../../README.md) · 숫자는 [balance.md](../2-design/balance.md), 구현은 [engine.md](../2-design/engine.md)

v12는 v11에서 핵심이 아닌 것을 꺼 둔 판이다. 꺼 둔 것은 지우지 않고 `src/game.html` 맨 위 `FEAT` 스위치로 남겼다. 하나씩 다시 켤 때마다 이 문서에 규칙을 되살리고 [decisions.md](decisions.md)에 이유를 적는다.

## 무대
보통 벨트 4줄짜리 맵 하나(기본). 레일마다 흐르는 방향이 있다. 출고구에 닿은 상자는 사라졌다가 입고구에서 새 상자로 나온다. 라벨 색·색 띠·색 출고구는 없다(모두 같은 색).

## 신호 (무궁화 꽃이 피었습니다)
왼쪽 세로 신호등 하나.
- 초록: 직원이 등을 돌렸다. 일반 상자들이 이때 흩어져서 아무 쪽으로나 옆 레일로 한 줄씩 덜컹 옮겨 간다(한 초록에 한 번까지).
- 노랑: 직원이 돌아보는 중. 일반 상자는 새로 옮기지 않는다(아주 가끔 늦게 옮기는 상자가 있다).
- 빨강: 직원이 보고 있다.

빨강이 되는 순간 레일 사이에 걸쳐 있던 상자, 그리고 빨강 중에 움직인 상자는 "걸린 상자"가 되어 머리 위에 빨간 느낌표가 뜬다. 느낌표는 다시 초록이 되면 사라진다. 일반 상자도 가끔 늦게 걸리므로 느낌표가 곧 정답은 아니다.

## 숨는 쪽
- 분홍 화살표가 내 상자.
- 목표: 제한 시간 안에 금색 도장 칸 4개를 차례로 지나가기. 도장은 한 번에 하나만 보이고, 찍으면 지금과 다른 레일에 다음 도장이 뜬다. 일반 상자는 도장에 관심이 없으므로, 도장 레일로 옮겨 가는 순간이 위험하다.
- 조작은 하나뿐: 옆 레일로 넘어가기(약 0.4초 걸림). PC는 ↑↓(W·S), 폰은 화면을 위·아래로 밀기. 어디서든 언제든 움직일 수 있다.
- 지는 조건: 직원 스캔에 찍히거나 시간이 끝남.

## 찾는 쪽 (직원)
- 화면은 늘 보인다. PC는 Space, 폰은 "돌아보기" 버튼으로 신호를 건다(노랑 → 빨강 2.5초 → 초록). 한 번 돌아본 뒤 1초는 다시 못 건다.
- 스캔: PC는 커서에서 가장 가까운 상자(노란 고리)를 클릭. 폰은 한 번 눌러 고르고(노란 고리), 같은 상자를 한 번 더 눌러 스캔. 언제든 가능, 판당 6번, 틀리면 5초 깎임.
- AI 모드에서는 숨은 사람 셋이 각자 도장 4개를 노린다. 화면에 그들의 도장이 셋 다 보인다. 셋 다 찾으면 승리, 한 명이라도 도장을 다 찍고 빠져나가거나 스캔을 다 쓰거나 시간이 끝나면 패배.

## 공통
- 난이도는 보통 하나. 일시정지(PC Esc, 폰 왼쪽 위 버튼): 계속하기·처음부터·메뉴로.
- 폰은 가로로만 한다. 세로로 들면 "가로로 돌려 주세요" 가림막이 뜨고 판이 멈춘다.

## 꺼 둔 것 (FEAT 스위치, v11 규칙 그대로 남아 있음)
속도 조절(진행 방향키 빠르게·반대 느리게, 속도를 바꾸다 빨강이면 걸림), 걸린 척(C), 라벨 색과 색 출고구(일반 상자가 자기 색 레일 쪽으로), 특수 칸 맵(빠른·느린 벨트, 정체, 재분류), 난이도 선택, 맵 만들기, 기록 화면, 우클릭 핀. v11 규칙 전문은 `archive/v11.html` 메뉴 화면과 git 기록에 있다.
