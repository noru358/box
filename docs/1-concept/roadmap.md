## 1. 혼자 하기로 재미 검증 (지금)
v11을 사용자가 플레이하고 판정. 통과 기준: 숨는 쪽에서 도장 레일로 옮길 때 손에 땀이 나고, 찾는 쪽에서 신호 타이밍을 노려 사람을 좁혀 갈 수 있다. 안 되면 규칙부터 다시 본다.

## 2. 친구와 하기 (멀티 시험판)
같은 링크를 연 사람끼리 한 방. 한 명은 직원, 나머지는 상자. 서버는 "신호 상태, 각 상자의 위치·이동"만 맞추면 되고, 일반 상자는 시드를 같게 해서 각자 계산한다. 시험은 claude.ai 아티팩트의 실시간 방 기능으로 할 수 있다(링크를 공유받은 사람끼리만). 실제 출시용은 4단계에서 다시 만든다.

## 3. 맵 다양화
칸 종류 추가 후보: 회전판(레일 방향이 주기적으로 바뀜, 지금 엔진에 코드는 남아 있음), 합류, 승강기, X선 게이트(지나가면 반응). 새 칸마다 "숨는 쪽이 들킬 새 상황"과 "그걸 숨기는 새 요령"이 같이 생겨야 한다. 맵 공유는 지금의 문자열 방식에서 출발.

## 4. 출시 쪽
고도(Godot) + GodotSteam으로 옮겨 스팀 로비·P2P 멀티. 로우폴리 3D 상자, 물류센터 소품, 근접 음성은 나중에 검토.

## 검토 중 (하기로 정하지 않음)
- AI 직원 시야(2026-11-04 사용자 제안): 직원이 보는 쪽만 적발하거나 가중치. 의견은 가중치 쪽, 화면 표시는 바닥 조명 정도, 우선순위는 낮음(멀티에서 직원은 사람이 됨). HANDOFF 열린 질문.
- 숨는 쪽 능력 추가(라벨 바꿔치기 같은 것) — 지금은 걸린 척 하나만.
- 찾는 쪽 도구(범위를 좁혀 주는 나침반식 장치) — 멀티에서 숨는 사람이 여럿일 때 다시 본다.
- 트위치 시청자가 상자로 참여.
