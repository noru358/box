# 조절 손잡이와 지금 값

숫자를 바꿀 때는 이 문서와 코드를 같이 고친다. 위치는 `src/engine.js`의 `DIFF`, `SPD`, `BASE`, `STAMPS`, `WANDER`와 `src/game.html`의 `PERS`, `start()`, `huntStep()`.

## 난이도표 (DIFF)
노란불 길이(초): 쉬움 0.65, 보통 0.45, 어려움 0.3. 숨는 쪽 체감 난이도를 가장 크게 바꾸는 값.
일반 상자가 노랑에 늦게 옮기는 빈도(late): 0.35 / 0.22 / 0.12. 높을수록 일반 상자도 자주 걸려서 숨는 쪽에 유리(미끼가 많아짐).
AI 직원 초록 길이 범위(green, 초): 1.6~4.2 / 1.0~3.8 / 0.6~3.4.
AI 직원 빨강 길이 범위(red, 초): 1.4~2.4 / 1.6~2.8 / 1.8~3.2.
짧은 초록으로 낚을 확률(fake): 0.12 / 0.2 / 0.3.
AI 직원 조준 시간(aim, 초): 1.0 / 0.75 / 0.55.
제한 시간 여유(slack, 보정값에 곱함): 1.6 / 1.25 / 1.0.
숨은 AI 실수 배율(k): 1.4 / 1 / 0.7.

## 고정값
- 기본 속도 1.25칸/초, 빠른 벨트 ×1.55, 느린 벨트 ×0.6. 숨는 쪽 빠르게 ×1.45, 느리게 ×0.6.
- 옆 레일 넘어가기 0.38초.
- 도장 목표 4개. 상자 수 = 칸 수 × 0.42.
- 찾는 쪽: 빨강 2.5초, 다시 걸기까지 1초, 스캔 6번, 틀리면 −5초.
- 숨는 쪽: 걸린 척 2번(1.5초). AI 직원 스캔 15번, 틀리면 3초 멍함.

## v12 (덜어낸 판) 값과 측정 (2026-11-03)
- 난이도는 보통 고정. 위 표의 보통 열만 쓴다.
- `WANDER` 0.45: 색 끔일 때 일반 상자가 초록에 옆으로 옮기는 빈도(초당, 한 초록에 한 번까지). 초록 한 번에 옮기는 일반 상자가 색 켬 때(약 14개)와 비슷하게 맞춘 값(약 12~15개).
- 빨간불 한 번에 걸리는 일반 상자(미끼): 기본 맵 색 끔 약 0.6~1개. 색 켬(v11) 약 0.2개보다 많다. 찾는 쪽이 느낌표만 보고 찍기 어려워지고 숨는 쪽은 숨기 쉬워진다. 숨는 쪽이 너무 쉬우면 `late`(노랑에 늦게 옮기는 빈도)부터 줄인다.
- 기본 맵(색 끔) 모범 플레이 보정값 약 20초 → 숨는 쪽 제한 시간 = max(30, 보정값 × 여유) + `HIDE_EXTRA`(7초, game.html) = 37초. 찾는 쪽은 60초. 사용자 판정: 30초는 약간 부족, 5~10초만 더.
- 폰 조작: 스와이프 문턱 22px(`SWIPE`), 터치 스캔 잡는 반경 칸 크기 × 1.05(마우스는 × 0.8).

## 찾는 쪽 (2026-11-04)
- `SEEK_DENSITY` 0.28(game.html): 찾는 쪽 판 상자 수 = 칸 수 × 0.28, 기본 맵 약 15개(숨은 셋 포함). 숨는 쪽은 0.42 그대로(미끼 적당 판정).
- `HUMAN_MIN` 12: 사람 기록이 초록 이만큼 모이면 숨은 AI가 기본 패턴 대신 사람 기록을 쓴다.
- 기본 패턴 숫자는 [ai.md](ai.md)의 숨은 AI 절.
- 찾는 쪽이 여전히 어렵다 → 먼저 `SEEK_DENSITY`를 0.22(약 12개)까지 내려 본다. 그래도 어려우면 기본 패턴의 늦은 움직임(0.8~2.6초) 비율을 올린다.

## v11 측정 결과 (2026-11-03, 엔진 테스트로 잰 값)
모범 플레이(초록일 때만, 도장 쪽으로만) 도장 4개 걸리는 시간 중간값: 기본(섞임) 약 30초, 다섯 줄 약 33초. 그래서 숨는 쪽 제한 시간은 기본 맵 기준 쉬움 48초, 보통 37초, 어려움 30초. 어려움은 모범 플레이 시간과 같아서, 한 번도 지르지 않으면 절반쯤은 시간이 모자란다.
신호를 보통 AI로 돌렸을 때 빨강 한 번에 레일 사이에 걸리는 일반 상자: 기본 맵 약 0.17개, 다섯 줄 약 0.3개(서너 번 돌아볼 때 한 번꼴로 미끼가 생긴다).

## 손볼 때 먼저 볼 것
- 숨는 쪽이 너무 쉽다 → 노란불을 줄이거나, 도장 근처 일찍 돌아보기 확률(0.9)을 올린다.
- 숨는 쪽이 억울하다 → 노란불을 늘리거나, 낚시(fake)를 줄인다.
- 찾는 쪽에서 아무도 안 걸린다 → 숨은 AI의 react를 늘린다(노랑을 늦게 알아챔).
- 찾는 쪽에서 느낌표가 너무 많다 → late를 줄인다(일반 상자 미끼 감소).
