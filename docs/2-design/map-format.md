# 맵 공유 문자열과 편집기

← [문서 지도](../../README.md)

## 문자열 형식
줄은 `/`로, 칸은 공백으로 나눈다. 칸 하나는 기호 2~3글자. 첫 글자 = 종류, 둘째 글자 = 방향(`>` 오른쪽, `v` 아래, `<` 왼쪽, `^` 위), 셋째 글자 = 색 번호(필요할 때).

- `..` 빈 칸
- `n>` 보통 벨트, `f>` 빠른 벨트, `s>` 느린 벨트
- `I>` 입고구(상자가 나오는 곳, 흰 화살표)
- `X>0` 출고구, 색 0~4 (0 파랑, 1 주황, 2 초록, 3 보라, 4 빨강)
- `J>` 정체 칸(빨간불 기둥, 주기적으로 열림)
- `C>3` 재분류 칸(지나가면 라벨이 색 3으로)
- `T>v2` 회전판: 방향 두 개(`>`와 `v`)를 숫자(초) 주기로 번갈아. 엔진엔 남아 있지만 편집기에서는 뺐다(위에서 레일을 옮길 수 없어서 숨는 쪽이 할 게 없었음).
- 옛 기호 `S`(분류기), `G`(X선)는 읽을 때 보통 벨트로 바뀐다. 옛 문자열도 깨지지 않게 하려는 것.

예: 4칸짜리 한 줄 `I> n> n> X>0`. 입고 → 벨트 두 칸 → 파랑 출고.

맵이 돌려면 입고구와 출고구가 하나 이상 있어야 하고, 숨바꼭질이 되려면 출고 색이 둘 이상이어야 한다. 레일끼리 위아래로 붙어 있어야 옮겨 탈 수 있다.

## 기본 맵 만들기 (코드)
`MAPS`에 `{name, str}`로 넣는다. 가로줄 레일 맵은 `laneMap(rows, [])`로 만든다. `rows`는 레일마다 `{d:'>'|'<', sp:'n'|'f'|'s', c:색, ex:{열번호:'기호'}}`. 입고·출고는 방향에 맞춰 양 끝에 자동으로 놓인다. 지금 맵: 기본(섞임) 4줄, 다섯 줄.

## 편집기 (게임 메뉴 → 맵 만들기)
14×8 칸. 도구를 고르고 칸을 클릭·드래그해서 칠한다. R = 방향 돌리기, 색 버튼 = 출고·재분류 색. 도구: 지우개, 벨트(보통·빠름·느림), 정체, 재분류, 출고, 입고. "편집 끝"을 누르면 공유 문자열이 나오고, 저장·복사·붙여넣은 문자열 불러오기를 할 수 있다. 저장한 맵은 메뉴의 맵 목록에 "내 맵"으로 뜨고, 제한 시간도 자동으로 맞춰진다.
