# 맵 공유 문자열

← [문서 지도](../../README.md)

## 문자열 형식
줄은 `/`로, 칸은 공백으로 나눈다. 칸 하나는 기호 2글자: 첫 글자 = 종류, 둘째 글자 = 방향(`>` 오른쪽, `v` 아래, `<` 왼쪽, `^` 위). 종류는 `src/engine.js`의 칸 등록표 `TILES`에서 나온다.

- `..` 빈 칸
- `n>` 벨트
- `W>` 분기 칸: 일반 상자는 여기서만 옆 레일로 넘어간다(바로 앞뒤 칸에서 가끔 미끼). 노란 판.
- `U>` 터널 칸: 덮개 아래, 찾는 쪽에게 안 보임. 옆 칸도 터널이면 안에서 갈아탈 수 있다. 덮개 바깥쪽에만 벽이 선다.
- `I>` 입고구(상자가 나오는 곳, 흰 화살표)
- `X>` 출고구(모든 상자를 받는다). 옛 문자열의 `X>0`처럼 붙은 색 번호는 무시한다.
- 방향은 네 방향 다 된다. 세로로 흐르는 레일(`v`, `^`)이면 옆 레일 넘기는 ←→(폰은 좌우로 밀기)가 된다(엔진 테스트 11).
- 등록표에 없는 기호(옛 `f` `s` `J` `C` `T` `S` `G`)는 빈 칸으로 읽힌다. v13.3에서 지웠다(이유는 decisions.md).

예: 한 줄 `I> n> W> n> X>`. 입고 → 벨트 → 분기 칸 → 벨트 → 출고.

맵이 돌려면 입고구와 출고구가 하나 이상 있어야 하고, 레일끼리 위아래(세로 레일이면 좌우)로 붙어 있어야 옮겨 탈 수 있다. 분기 칸이 하나도 없는 맵이면 일반 상자는 초록 때 아무 데서나 옆으로 옮긴다(`WANDER`).

## 기본 맵 (코드)
`MAPS`에 `{name, str}`로 넣는다. 가로줄 레일 맵은 `laneMap(rows, 폭)`. `rows`는 레일마다 `{d:'>'|'<', ex:{열번호:'기호'}}`, 입고·출고는 방향에 맞춰 양 끝에 자동으로 놓인다. 지금 맵: 세로 폰용 9칸(`compact`, 기본), 분기(`switch`), 굽은 길(`loop`).

## 새 칸 종류 넣기
`engine.js` `TILES`에 `{sym, name, make(d)}` 한 줄(규칙은 `make`가 돌려주는 칸 속성 `t`·`sw`·`tun`으로), `src/view/tiles.js` `TILE_LOOK`에 그리는 법 한 줄. 새 규칙이 필요하면 엔진에서 그 속성을 읽는 곳을 더한다.

## 맵 편집기
v13.3에서 옛 편집기(v11 칸 팔레트)를 지웠다. 로드맵 3단계에서 `TILES`를 팔레트로 읽는 새 편집기를 만든다.
